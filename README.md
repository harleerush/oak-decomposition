Oak litter decomposition

This repository contains the data and R code associated with a study examining litter decomposition and home-field advantage between two oak species across upland and bottom land habitats in northeastern Ohio.

Repository contents

Data
The data folder contains the datasets used in the analyses:

GPD_MassLoss.K_All.xlsx — litter mass loss and decomposition rate data
MassLoss_HFAI.xlsx — HFAI data
AllData_with chemicals_ALL.samples.xlsx — litter chemistry data
Geauga_LeafThickSA_PinVSRed.xlsx — leaf physical trait data

R code
The R script contains the analyses used to examine litter decomposition, litter chemistry, physical leaf traits, and home-field advantage.

Study system
The study was conducted in Geauga Park District forests in northeastern Ohio using reciprocal litterbag experiments with northern red oak (Quercus rubra) and pin oak (Quercus palustris) litter.

Reproducibility
The R code uses relative file paths to access the datasets in the data folder. Required R packages are identified within the analysis script.
